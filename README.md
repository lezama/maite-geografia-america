# ¡América con Maite! 🌍🐱

Un juego educativo interactivo creado por **Maite** para aprender la geografía de América — los 28 países del continente, sus capitales y datos curiosos — acompañada de **Pusheen**, su mascota favorita.

🎮 **Jugar online**: [lezama.github.io/maite-geografia-america](https://lezama.github.io/maite-geografia-america/)

## ¿Cómo se juega?

1. Aparece la bandera y el nombre de un país de América.
2. Maite busca el país en el mapa real y lo toca.
3. Después tiene que elegir la capital correcta entre 3 opciones (con una pista visual: una estrella ⭐ en la ubicación de la capital).
4. **Solo cuando acierta país Y capital** el país queda marcado como aprendido ✓.
5. Cuando completa los 28 → 🏆 ¡celebración máxima!

## Lo que tiene

- 🗺️ **Mapa real** de América con fronteras geográficas verdaderas (Leaflet + GeoJSON).
- 🐱 **Pusheen** ilustrado en SVG que reacciona a la racha de aciertos (comiendo galletas, con globos, unicornio).
- 🦜 **Tuki el Tucán** que da pistas geográficas cuando se le pide.
- 🇬🇫 Incluye **Guayana Francesa** (territorio de Francia que muchos juegos olvidan).
- 💪 / 💡 Cuenta los aprendidos **sin pista** vs **con pista**.
- 🔥 **Rachas** con celebraciones especiales a las 3, 5, 8, 12 y 15 aciertos seguidos.
- 🎤 Voz hablada en español (activable).
- 📱 Diseñado para iPad — funciona también en desktop y móvil.

## Tecnología

- HTML + CSS + JavaScript vanilla
- [Tailwind CSS](https://tailwindcss.com/) (CDN) para estilos
- [Leaflet](https://leafletjs.com/) para el mapa interactivo
- [CartoDB Voyager](https://carto.com/) para los tiles del mapa
- [Natural Earth](https://www.naturalearthdata.com/) para las fronteras
- [Web Speech API](https://developer.mozilla.org/docs/Web/API/Web_Speech_API) para voz
